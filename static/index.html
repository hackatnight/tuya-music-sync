Timing

Prediction locks onto steady kicks ("LOCKED" by the BPM) and fires each flash early by the light latency so it lands on the beat. Set the latency with the Sync test: raise it until the flashes land on the clicks.

Fade time: seconds for one trip round the rainbow. Colour step: how far the colour moves on each beat. Delay: if the lights run ahead of the sound (e.g. Bluetooth speakers), add delay.

Sync test

Plays a click at 120 BPM from this device's speakers and flashes the strips exactly on each click, so you can see whether the strips keep time.

Use Colour mode. The music modes switch on the strips' own built-in-mic effect, which changes colours by itself. The method applies to music sync too, and the Delay slider above also shifts the test flashes.
